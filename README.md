# 摸鱼阅读 · macOS · 作者 yu1

一个本地 TXT 悬浮阅读器。无需安装 Xcode、Node 或 Python。

## 使用

下载【MoyuReader安装包.zip】打开 `dist/MoyuReader.app`，点击「导入 TXT」选择小说。可将应用拖入「应用程序」文件夹。

下载压缩包中，应用直接位于 `MoyuReader/MoyuReader.app`，源码与构建脚本位于 `MoyuReader/Source/`。

- **背景透明度**：0%–100%，只改变背景，文字保持不透明。
  拖动时只更新背景与百分比，不重新排版正文或逐次写入文件；由自动保存和退出保存记录设置。
- **纯色文字**：深色背景为纯白字，浅色背景为纯黑字，关闭文字描边和窗口阴影。
- **全局隐藏 / 恢复**：⌥Z，同一个快捷键切换；在其他应用里也能用。
- **置顶**：点击「置顶：开 / 关」切换。
- **字号**：使用 A− / A+，范围 12–32。
- **背景颜色**：深色 / 浅色切换。
- **收起 / 展开**：⌥X，收起时隐藏标题、作者、工具栏及底部信息，只留下正文和「展开」按钮。
- **目录识别**：默认关闭，每本书需手动点击「识别目录：关」开启，再从下拉目录选择章节跳转。
- **行间距**：滑块调整额外行距 0–40 pt，松手后生效；自动保存，下次启动沿用。
- **搜索定位**：输入文字后按回车或点「下一处」，滚动到匹配位置并选中；支持「上一处」和首尾循环，英文不区分大小写，标点按原文查找。
- **进度**：每两秒保存，退出时也保存；启动后恢复上一本书。
- **编码**：UTF-8、GB18030（含常见 GBK 中文文本）、带 BOM 的 UTF-16。

支持滚轮、触控板以及正文获得焦点时的方向键与翻页键。拖动窗口顶部移动，拖动边缘改变大小。

| 快捷键 | 操作                       |
| --- | ------------------------ |
| ⌘O  | 导入 TXT                   |
| ⌘F  | 打开搜索；收起状态下自动展开           |
| ⌘G  | 定位下一处                    |
| ⌘⇧G | 定位上一处                    |
| ⌘T  | 收起 / 展开工具栏               |
| ⌘P  | 切换置顶                     |
| ⌘H  | 隐藏窗口（点击 Dock 图标恢复）       |
| ⌥Z  | 隐藏 / 恢复窗口（全局使用需先授权辅助功能）  |
| ⌥X  | 收起 / 展开阅读器（全局使用需先授权辅助功能） |
| ⌘Q  | 保存并退出                    |

## 启用全局快捷键

阅读器窗口获得焦点时，⌥Z 和 ⌥X 无需授权即可使用。隐藏后可点击 Dock 图标恢复。

1.3.1 修复：在窗口分发按键给正文、搜索框或按钮前处理 ⌥Z / ⌥X，避免 Option 组合键被当前控件当作普通文字处理；外部应用的全局监听保持不变。

在其他应用里使用时，点击窗口顶部「启用全局快捷键」，在「系统设置 → 隐私与安全性 → 辅助功能」允许当前版本的「摸鱼阅读」。回到应用，按钮显示「全局快捷键：开」后再尝试。若没有更新状态，退出并重新打开阅读器。

快捷键也能恢复最小化的窗口。应用需保持运行；⌘Q 退出后需重新打开应用。未授权时，只能在阅读器获得焦点时用该快捷键，或点击 Dock 图标恢复。

全局快捷键只匹配 ⌥Z、⌥X，忽略长按重复，不保存或上传按键信息。升级后若授权失效，请从辅助功能列表移除旧条目，重新添加当前版本，再重启应用。

应用仅在本机处理文本，不联网。单文件上限 30 MB；导入后缓存当前小说，各文件进度分别记录。数据位于 `~/Library/Application Support/MoyuReader/`，删除该目录可清除缓存与进度。此版本仅保留上一本小说的正文缓存；重读其他书请重新导入。

## 目录识别规则

识别独立成行的常见标题，例如「第一章 起点」「第12回」「第三卷」、英文「Chapter 3」「Part II」，以及「序章」「楔子」「尾声」「番外」等。按原文顺序列出，重复章节名保留各自位置。无规范标题的文本可能无法识别，正文中单独成行且形似章节名的内容可能被识别为标题。

每次启动或导入新书，目录识别恢复关闭，需再次手动开启。收起时目录、行距和搜索控件一并隐藏；已识别目录及当前搜索保留，展开后继续使用。搜索只定位文字，不会修改小说内容。

## 重新构建

双击 `build.command`，或在当前目录执行 `zsh build.command`。

源码为 `reader.js`，使用 macOS 自带的 JavaScript for Automation 和 AppKit 原生控件，通过 `osacompile` 打包。应用未进行 Developer ID 签名或公证；如系统拦截，请在确认来源后通过系统「隐私与安全性」允许打开。

开发验证：`osascript -l JavaScript reader.js --self-test`。

当前验证结果：连续 101 次原生透明度滑块动作不修改正文样式、不逐次保存文件，保持选区和阅读位置，正确更新透明度及百分比；原生窗口按键分发、目录、搜索、行距、收起显隐、启动缓存及原有功能检查继续通过。当前环境无法连接 macOS 桌面会话，尚未完成真实桌面拖动流畅度及跨应用快捷键验证。
